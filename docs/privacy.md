# Privacy & safety
All medication names, schedule information and dose logs remain on device in platform-backed encrypted secure storage. The app does not contain analytics, advertising SDKs or remote API calls. The user can erase the entire local journal. The export dialog displays plaintext JSON; copying or sharing that text leaves the app's secure storage protection. Do not store the plaintext export in shared documents. No account or server exists. App deletion generally removes app data; device backups and OS keychain retention may differ by platform and require release testing. Not a substitute for a pharmacist or physician.
